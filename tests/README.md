# Club FM battle test suite

Rerun after any change. Live site, read only: test visits never reach the visit counter, nothing is posted or sold.

1. `node tests/pages.cjs <chromium|android|webkit|firefox> [out.json]`: every page type, plus dark, 320 px, landscape, reduced motion, 200% zoom. Status, script errors, broken images, layout shift, sideways scroll, titles, unlabeled controls, load over 3 s on phones. `SWAP=1` serves this checkout's board.
2. `node tests/features.cjs [out.json]`: search inputs, deep links and Discord link formats, Worker down, GitHub raw down or slow, empty or broken data, offline, slow 3G, two tabs, HTML in seller names.
3. `node tests/memory.cjs 60`: one board tab for an hour, heap every 5 minutes.
4. `node tests/bot.mjs <worker copy>`: 60 queries through !price, /price and /sell code locally (see the file head for the exports to add). Outside requests are blocked.
5. `node tests/visits.mjs` from a worker/src copy: the visit counter counts real visits and skips headless browsers, bots and cloud servers.
6. `bash tests/endpoints.sh`: every public Worker route, admin and member routes without a session. One request a second.

Playwright: `NODE_PATH=$(npm root -g)` in this container. WebKit and Firefox run in CI only.
7. `node tests/advsearch-ux.cjs [chromium|webkit]`: Search by stats used like a person on an iPhone: pick a type, type a stat total, "or more", typed stats then edited in the panel, the Show button scrolling to the results, a shared link, and no leftover stats after closing. Any change to Search by stats runs this first.
8. `node tests/sitesearch-ux.cjs [chromium|webkit] [phone|desktop]`: Search the site, the green button at the end of the menu: it sits at the right end on every page, finds monsters, items, quests and maps, the preview's numbers match data/sitesearch.json and the pages, an item's price shows only when the board is sure, Enter opens the page, Esc closes, and test visits send nothing to the visit counter.
9. `python3 tests/links.py [build]` and `node tests/pages-ux.cjs [build]`: the built item, monster, quest, map and training pages. Every link lands on a page that exists; desktops show cards in columns, phones show tabs; every exit is numbered on the minimap and its number key opens it; Directions light only the portal to take, with a short bar on a computer and their own screen on a phone; the mini window shows the map and exits only.
10. `python3 tests/sitewalk.py [data dir] [out.json]`: every page and every link in this checkout, the way a crawler sees it. Links land on pages that exist; #item=, #q-, #route= and #map= links name a real item, quest or map; pages nothing links to; pages with no way home; breadcrumbs, menu and footer per page type; clicks from the board to every page. Data dir holds world.json, itemguide.json and summary-public.json from the live branch.
11. `node tests/wayfinding.cjs [desktop|phone|both] [out dir]`: ten real trips through the live site (BASE= for a local copy), clicks and Backs counted: Back keeps the board search, card, quest and filters; the mini window stays mini; Directions from Where to train on a phone; every page type has a way home. Lines marked "idea" are gaps waiting on Adam's OK, not failures.
12. `node tests/getting-around.cjs [base url]`: map pages list the quests that hunt there, help pages have breadcrumbs and a lit menu item, the Guides hub is wide, the Top button works, phone menu taps are 40 px, and the phone board's menu slides back in on scroll up and away on scroll down.
13. `node tests/smooth-ux.cjs [chromium|webkit] [phone|desktop]`: the board scrolled by finger swipes on an iPhone or a mouse wheel on a desktop. Rows keep arriving and never repeat, board icons load with their row, the Big sales strip holds still while scrolling and slides again after, a search typed mid-scroll leaves no old rows, a card opens and closes back to the same place. Prints frame times; fails only past 40% of frames over 33 ms.
